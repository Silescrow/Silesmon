# SILESMON

Monster zähmen und kämpfen – mobiles 3D-Browser-Spiel fürs Handy. Hier liegen alle Dateien, die das Spiel benutzt, und alle Spielversionen.

**Online spielen:** https://silescrow.github.io/SilesmonGithub/

| Ordner | Inhalt |
|---|---|
| `00_Spielplan.md` | Geschichte, Regeln und Reihenfolge – alles, was fürs Spiel beschlossen ist |
| `01_Hauptmenue` | Cover (Siles mit Fernglas, riesiger Brisko auf der Ruine), Logo-Schriftzug; älteres Cover in `Alt/` |
| `02_Ladebildschirm` | Bilder für einen Ladebildschirm – im Spiel seit V1.05 nicht mehr benutzt |
| `03_Spieler` | Figurenblatt von Siles (vorne, seitlich, hinten) |
| `04_Monster` | Figurenblätter der 10 Monster: `Nummer_Name_Tier_Typ` |
| `05_Trainer` | Figurenblätter der 4 Trainer (Feuer, Wasser, Pflanze, Luft/Erde) |
| `06_Musik` | Musik fürs Hauptmenü |
| `07_Alle_Versionen` | alle Spielversionen ab `V1.00`, fortlaufend nummeriert (+0.01 pro Version); die neueste läuft online als `index.html` im Repository `SilesmonGithub` |
| `08_App` | App-Icons und `manifest.webmanifest` für die installierte App (liegen zum Spielen auch in `SilesmonGithub`) |
| `09_Vorlagen` | Vorlagenbilder für den Stil der Welt (z. B. das Bilderbuch-Haus) |
| `10_3D_Modelle` | eigene 3D-Modelle als GLB (bisher: das Fachwerkhaus) |

Zum Spielen reicht die neueste Datei in `07_Alle_Versionen` – alle Bilder und Töne sind dort eingebaut.

## Stand

Aktuell: **V1.12** – Hauptmenü und das Dorf Wiesengrund in 3D (herumlaufen, Kamera drehen, Häuser, Schilder und die Heilerin ansehen). Wie es weitergeht, steht in `00_Spielplan.md`.
