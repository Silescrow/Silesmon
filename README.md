# SILESMON

Monster zähmen und kämpfen – mobiles 3D-Browser-Spiel fürs Handy. Hier liegen alle Dateien, die das Spiel benutzt, und alle Spielversionen.

**Online spielen:** https://silescrow.github.io/SilesmonGithub/

| Ordner | Inhalt |
|---|---|
| `01_Hauptmenue` | Cover mit eingebautem Logo, Logo-Schriftzug; ältere Cover in `Alt/` |
| `02_Figurenblaetter` | Siles, `Monster/` (10 Monster: `Nummer_Name_Tier_Typ`), `Trainer/` (4 Trainer) |
| `03_3D_Modelle` | eigene 3D-Modelle als GLB: Fachwerkhaus, Siles mit Skelett (Gehen, Rennen), Tanne |
| `04_Musik` | Musik fürs Hauptmenü |
| `05_Geraeusche` | Geräusche (noch leer) |
| `06_Texte` | `Spielplan.md`: Geschichte, Regeln und Reihenfolge – alles, was fürs Spiel beschlossen ist |
| `07_Vorlagen_Bilder` | Vorlagenbilder für 3D-Modelle und Stil (Haus, Siles in T-Pose) |
| `08_App` | App-Symbole und `manifest.webmanifest` für die installierte App |
| `09_Alt` | nicht mehr benutzte Dateien (Ladebildschirm) |
| `10_Alle_Versionen` | alle Spielversionen von `V1.00` bis heute, fortlaufend nummeriert (+0.01 pro Version); die neueste läuft online als `index.html` im Repository `SilesmonGithub` |

Zum Spielen reicht die neueste Datei in `10_Alle_Versionen` – alle Bilder, Modelle und Töne sind dort eingebaut.

## Stand

Aktuell: **V1.19** – Hauptmenü mit Cover und Musik, das große Dorf Wiesengrund in 3D mit Tutorial, Gesprächen, Geräuschen und Speichern. Wie es weitergeht, steht in `06_Texte/Spielplan.md`.
